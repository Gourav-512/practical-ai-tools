## 2. Text Cleaner (Python)

Quick script to clean messy text from PDFs, WhatsApp exports, or copied content.

```bash
cd tools/text-cleaner
python cleaner.py input.txt
```

---

## 3. Simple AI Chat UI

Minimal Next.js starter connected to OpenRouter (supports Grok, Claude, GPT, etc.).

```bash
cd tools/ai-chat-ui
npm install
cp .env.example .env.local
npm run dev
```
