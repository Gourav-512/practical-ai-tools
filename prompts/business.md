# Business & Startup Prompts

## Cold Email

```
Write a short cold email to [ROLE] at [COMPANY TYPE].

Goal: [meeting / feedback / collaboration]
My background: [1-2 lines]
Value I can provide: [clear benefit]

Tone: Direct, respectful, no fluff.
Length: Under 120 words.
```

## Product Description

```
Write a clear product description for [PRODUCT].

Target user: [who]
Main problem it solves: [problem]
Key features: [list]

Style: Benefit-focused, simple language.
```

## Startup Idea Validator

```
I have this idea: [DESCRIBE IDEA]

Help me pressure-test it:
1. Who is the real target customer?
2. What existing alternatives do they use?
3. Why would they switch?
4. Biggest risk / assumption?
5. Simple way to test this in 7 days?
```
