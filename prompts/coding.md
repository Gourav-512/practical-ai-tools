# Coding & Debugging Prompts

## Debug Helper

```
I'm getting this error:

[PASTE ERROR]

Code context:
[PASTE RELEVANT CODE]

Explain the root cause in simple words and give the fixed code.
```

## Code Explainer

```
Explain this code step by step like I'm a junior developer:

[PASTE CODE]

Also mention any potential edge cases or improvements.
```

## Refactor Request

```
Refactor this code to make it cleaner and more maintainable.

Requirements:
- Keep the same functionality
- Improve naming
- Reduce duplication
- Add brief comments only where necessary

[PASTE CODE]
```

## Write Tests

```
Write unit tests for the following function using [Jest / pytest / vitest].

Cover:
- Happy path
- Edge cases
- Error cases

[PASTE FUNCTION]
```
