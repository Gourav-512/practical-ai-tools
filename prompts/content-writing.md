# Content Writing Prompts

## LinkedIn Post (Professional but Human)

```
Write a LinkedIn post about [TOPIC].

Tone: Professional but conversational, no corporate jargon.
Length: 120-180 words.
Structure:
- Hook in first line
- 2-3 short paragraphs
- One clear takeaway
- Soft CTA at the end

Audience: [developers / founders / freelancers]
```

## Blog Outline Generator

```
Create a detailed blog outline for the topic: "[TOPIC]"

Target audience: [who]
Goal of the article: [educate / convert / rank]

Include:
- SEO-friendly title options (3)
- Introduction angle
- H2 and H3 structure
- Key points under each section
- Conclusion with CTA
```

## Twitter / X Thread

```
Write a Twitter thread (8-12 tweets) about [TOPIC].

Style: Clear, slightly opinionated, valuable.
First tweet must be a strong hook.
End with a question to encourage replies.
```
